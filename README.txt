MINISHOP - BÀI TẬP HTML, CSS, JAVASCRIPT CƠ BẢN

Cách chạy:
1. Giải nén thư mục minishop.
2. Mở thư mục bằng Visual Studio Code.
3. Mở file index.html bằng trình duyệt hoặc dùng tiện ích Live Server.
4. Các trang khác có thể mở qua menu điều hướng.

Cấu trúc:
minishop/
|-- css/style.css
|-- js/main.js
|-- images/
|-- index.html
|-- about.html
|-- product.html
|-- cart.html
|-- register.html
|-- login.html
|-- contact.html

Chức năng:
- Hiển thị danh sách sản phẩm mẫu.
- Tìm sản phẩm theo tên hoặc danh mục.
- Xem chi tiết sản phẩm.
- Thêm sản phẩm vào giỏ hàng.
- Đổi số lượng, xóa sản phẩm, tính tổng tiền.
- Lưu giỏ hàng bằng localStorage.
- Đăng ký và đăng nhập demo.
- Kiểm tra biểu mẫu liên hệ.
- Giao diện co giãn theo màn hình.

Lưu ý:
- Ảnh sản phẩm là ảnh minh họa. Nếu chưa có ảnh trong thư mục images,
  trang sẽ hiển thị ảnh thay thế từ placehold.co khi có Internet.
- Đăng nhập chỉ dùng để thực hành front-end. Mật khẩu lưu trong localStorage
  không an toàn; không dùng cách này cho website thật.
- Chưa có máy chủ, cơ sở dữ liệu hoặc thanh toán thật.
